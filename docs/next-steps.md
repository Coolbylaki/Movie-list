# Agreed feature roadmap

Add and test each feature separately before moving to the next one.

1. **Open movie folder**: complete and confirmed working by the user. Available for unmatched movies as well.
2. **Play movie**: complete and confirmed working by the user. Includes videos in subfolders and a file selector when multiple videos are found.
3. **Filters**: complete and confirmed working by the user. Genre, year, and minimum-rating selectors combine with search.
4. **Correct movie matches**: implemented with TMDB title/year search, poster previews, and an explicit selection/save step. Supports unmatched folders and preserves choices across refreshes and restarts. Awaiting user testing.
5. **Remember browsing preferences**: restore the selected sort and filters between launches.

Watched status, favorites, random picks, and offline poster/detail downloads are outside the agreed scope.

The dark interface refresh, approved icon, responsive toolbar, keyboard-accessible movie cards, native dialogs, and sort border fix are already complete.
